# In Between Chaos and Equilibrium Episode 1

***

## Project Name
In Between Chaos and Equilibrium Episode 1: Life is Peachy

## Description
IBCE is a First Person Shooter-Platforming game hybrid, combining the best aspects of 80s and 90s 2 dimensional platforming games and 90s and early 2000s 3 dimensional first person shooter games together. This game combines the retro and the modern, the futuristic and ancient, the old and the new, and the best parts of gaming together. This game is a love letter to everything video games, their players, and to God himself.

## Plot
In 2074 AD, despite the warnings of many previous prophets, nobody prevented a massacre from happening. This massacre, caused by a pagan ritual done in the heart of the returned and rebuilt Babylonian Empire, was a demonic war waged against the alien isorropians brought to Earth and its solar system. The people who didn't perish in the initial attack who are of God or of his allies are now tasked with defeating the alien isorropians and demons and expelling them from humanity's solar system.

### Also, for new game developers who have just joined this project, here is a tutorial on how to get started with working on the game

Step 1: Install GIT by clicking this link: https://www.git-scm.com/download/win

Step 2: Install Godot 3.6 by clicking this link: https://godotengine.org/download/3.x/windows/ 

Step 3: When both applications are downloaded, go into file explorer and open the directory you want to save a clone of IBCE in.

Step 4: Then right click and click, "open bash here."

Step 5: Then type into the terminal: "git clone https://github.com/pokefan1543/IBCEepisode1" (without the quotation marks of course).

Congradulations! You have now gotten a copy of the game onto your computer so you can work on everything! 

Now, make sure that any time you make changes to the game, you never make them in the master branch. Only Noah Lanier can set what is in the master branch. Always make changes in another branch than master. If you watched the videos, you would know how to make a new branch.
